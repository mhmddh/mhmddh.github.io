## Deployment

1. Create a **public** repository named `mhmddh.github.io` under the `mhmddh` account. If you already have that repository, use it instead.
2. Upload the **contents** of this folder to the root of the repository (`index.html` must be at the root).
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Visit https://mhmddh.github.io/ after GitHub Pages finishes deploying.

## Local preview

Open `index.html` in a browser. No dependencies or build step are needed.

## Customize

Edit `index.html` to update experience, research projects, and links. Edit `styles.css` to change colors or layout.

The chart on the thesis project card is a decorative illustration, **not actual experimental data**.
